# LocalMind 🧠

**给 AI 配个本地小本本，别让你每天都在演《前情提要》。**

> 你：按我们之前定的方案继续。
>
> AI：当然可以！请先告诉我项目背景。
>
> 你：……我们刚聊了两个小时。

聊得越久，越容易多出一份工作：**给 AI 当专职前情提要员。**

换个对话要重新介绍项目；要求已经改了，它还抱着旧版不撒手；你说“选第二个”，它记住了这五个字，却忘了第二个到底是什么。

LocalMind 想把这些事交给电脑：把你明确说过的要求、做过的选择和相关原文留在本地，下次需要时，带着依据拿出来。

**目标分工：大模型负责动脑，本地小本本负责记事。大脑可以换，项目别从头讲。**

目前是 **v0.5 开发原型**：命令行、本地 Ollama 回答和 MCP 记忆接口已有实现与测试。ChatGPT / Codex 里的每轮自动采集和补充还在施工，暂时没有“装上就从此懂你”的魔法按钮。

## 这个小本本，具体记什么？

| 场面 | LocalMind 的处理方式 |
|---|---|
| “有效期改成 2 小时，24 小时那个作废。” | 显式修订后，保留新要求，让旧值退出当前状态。需求变了，旧圣旨就该退位。 |
| “我选第二个。” | 对明确的编号选择，关联当时的方案原文，查清“第二个”究竟是啥。 |
| 换个会话接着干 | 沿用同一项目和任务，读取已保存的有效状态。少办一次“新同事入职培训”。 |
| AI：“我建议用 Redis。” | 保留为助手提议，等用户确认。禁止“自己提议、自己批准”的闭环文学。 |
| 用 `/pause` 暂停，或 `/forget` 遗忘指定来源 | 提供暂停与按来源遗忘的控制。暂停后停止新采集；遗忘清理本地相关记录及派生内容。 |

**当前的可靠做法是用显式命令修订事项。** 普通中文原话可以保存，但随口一句“还是改成两小时吧”，还不能保证它自动找到并修改对应要求。这个坑已经记进待办，没拿宣传文案填平。

## 为什么不直接把聊天记录全塞回去？

完整历史是很强的办法，我们也把它当对照。问题是：项目会越聊越长，里面既有现在的要求，也有上周的废案、助手的建议和十次“算了”。

LocalMind 尝试每轮整理一份有出处的材料：**现在什么有效、这次需要哪些原文、哪里还不确定。** 原始记录留在本地，给模型的材料单独组织；同一来源尽量只放一份。关键条件装不下就明确报预算不足，保住“仅限测试环境”这样的前提。

MCP 可以理解成“让支持它的 AI 客户端来查小本本”的接口。当前提供四个只读工具：一次召回、查看状态、搜索历史、展开原文。保存和修订走受信的命令行入口，模型没有“替你拍板并记成事实”的写入工具。

## 实测战绩：香槟先放回冰箱

用同一个本地 `qwen3.5:9b`，跑了 11 个合成开发场景，比较五种提供上下文的方式：

| 给模型什么材料 | 本轮通过 |
|---|---:|
| 无历史、无记忆补充 | 3 / 11 |
| 最近两个有效历史回合 | 9 / 11 |
| LocalMind 整理的上下文 | 10 / 11 |
| LocalMind 通过 MCP 补充 | 11 / 11 |
| 完整有效历史 | 11 / 11 |

这批题在修复时已经见过，历史也短，属于开发练习题。**MCP 追平了完整历史；长期使用、陌生场景和真实宿主里的效果，还要继续考。**

而且这轮 MCP 输入 token 仍比完整历史多约 **47.5%**。小本本已经学会少复读，离“省钱小能手”还有距离。同义表达召回也仍有缺口，某一道 MCP 答对是靠近期原文回退，不能吹成已经学会通用语义理解。

另有 **100 项开发测试通过**，GitHub CI 已在 Python 3.9 和 3.12 上跑通。测试覆盖纠正、范围隔离、暂停、遗忘、重启和预算等行为。

## 先跑个不烧模型的演示

需要 Python 3.9+。核心只用 Python 标准库：

```bash
git clone https://github.com/jacobji-maker/LocalMind.git
cd LocalMind
python3 -m localmind demo
```

`demo` 是模拟回放，方便先看一遍记忆、纠正和遗忘的流程；它不会调用真实模型，也不会产生模型 API 费用。

已有 Ollama 和相应模型的朋友，可以试命令行聊天：

```bash
python3 -m localmind --project my-project init
python3 -m localmind --project my-project chat --model qwen3.5:9b
```

在聊天里，用这些命令明确记录和修改要求：

```text
/require cache_ttl=24小时
/correct cache_ttl=2小时
/inspect
```

程序不会自动下载模型。要接 MCP，或查看暂停、遗忘、跨会话等完整用法，走这边：[插件接入](docs/PLUGIN.md) · [运行与开发说明](docs/DEVELOPMENT.md)。

## 小本本放哪儿？

默认保存在运行目录的 `.localmind/`，按项目和任务区分。暂停和遗忘作用于本地记录；已经发给模型或宿主的内容，本地程序无法隔空撤回。

存储和推理的位置要分别看：这次实测使用本地 Ollama 模型。未来接云端模型时，被选中的记忆材料会随请求发送给对应服务，不能因为“小本本在本地”就把整条链路叫作离线。

公开仓库包含源码、设计和合成测试证据，本机记忆数据库及机器配置已排除。
